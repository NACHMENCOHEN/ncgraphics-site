FAQ

Common questions.

How many chadarim use the system?

18 chadarim use the cheder management system, each with its own personal design.

Is the system in Hebrew?

Yes. The cheder system is built in Hebrew with right-to-left layout and the Hebrew calendar.

Is student data secure?

The system is private by default, runs on HTTPS, and only staff with a login can see it. Access rules decide who sees what.

Can it be set up for our cheder?

Yes. Each cheder gets its own setup and design. Contact us on WhatsApp to talk about what your cheder needs.
